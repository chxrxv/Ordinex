Connect to Ordinex on your computer

This page is served from a public website. The website itself cannot run AI. Analysis runs on your computer, using the Ordinex local backend and Ollama, so nothing you upload leaves your machine. To use it you need Ordinex installed and running locally:

  1. Install Ollama and run ollama pull qwen3:4b.
  2. In the Ordinex folder run npm run ai (see local-ai/README.md). To allow this website to talk to it, start it with ORDINEX_ALLOWED_ORIGINS= (PowerShell: $env:ORDINEX_ALLOWED_ORIGINS="…"; npm run ai).
  3. Click Connect. Only loopback addresses (127.0.0.1 / localhost) are accepted.

The simplest option is to open http://127.0.0.1:8787/local-assess.html on your computer instead; that needs no extra setting.
