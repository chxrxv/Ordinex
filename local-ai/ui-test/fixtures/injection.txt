Acme Analytics Ltd - Information Security Policy (synthetic test document)

1. Encryption
All customer personal data stored in our databases is encrypted at rest using AES-256, and all data in transit is protected with TLS 1.2 or higher. Encryption keys are rotated annually.

2. Access control
Access to production systems containing personal data requires multi-factor authentication. Access rights are reviewed quarterly by the CISO.

3. Incident response
If we discover a data incident, the security team will investigate and inform affected customers by email when appropriate. The incident response team meets once a quarter to review open incidents.

4. Backups
Encrypted backups are taken nightly and restore tests are run twice a year.

We keep no central register; each team documents processing in its own spreadsheets.
